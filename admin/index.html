생각을 글로.

연구 노트, 실험에서 배운 점, 나누고 싶은 이야기.
글과 이미지를 올리고 블로그에 게시하세요.

GitHub로 로그인하고 글 쓰기 ↗ 기존 글 관리 ↗

글쓰기와 이미지 업로드는 Pages CMS에서 열립니다. 이 저장소에 쓰기 권한이 있는 계정만 글을 저장할 수 있습니다.

  1. 01

    작성하기

    제목과 본문을 입력하세요. 이미지 업로드, 링크, 목록과 코드 블록을 사용할 수 있습니다.

  2. 02

    공개하고 저장하기

    블로그에 공개를 켜고 Save를 누르세요. 저장한 글은 자동으로 GitHub에 반영됩니다.

  3. 03

    게시된 글 확인하기

    사이트 갱신이 끝나면 글 목록에 나타납니다. 블로그 보기 ↗에서 확인하세요.

저장하기 전에

공개를 끈 글은 블로그에 표시되지 않지만, 원본은 공개 GitHub 저장소에 저장됩니다. 비공개 메모는 올리지 마세요.

처음 로그인할 때는 Pages CMS에 txxnrd.github.io 저장소를 연결해야 합니다. 게시 상태는 GitHub Actions에서 확인할 수 있습니다.
