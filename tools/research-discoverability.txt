Update workflow

1. Verify titles, author order, dates, abstracts, and DOI against the published
   record or latest public author manuscript. Edit _data/research.json.
2. Run: python3 tools/build_research.py
   This refreshes seven paper pages, citation metadata, JSON-LD, and BibTeX.
   Existing project narratives outside the research:* markers remain editable.
3. When adding a paper, also add its visible card to publications.html, update
   the visible count, and add its canonical URL to sitemap.xml. The generator
   does not maintain the hand-authored publication list or sitemap.
4. Change sitemap lastmod only when the corresponding content changes.
5. Review the diff, check links, preview desktop/mobile, and deploy through the
   existing GitHub Pages branch. Never stage unrelated local research files.

Search Console follow-up (requires the existing site's owner account)

The Google account currently signed into Chrome could not access the existing
https://txxnrd.github.io/ Search Console property. No new owner was added.

1. Open https://search.google.com/search-console and select that property using
   its existing owner account.
2. Under Sitemaps, submit https://txxnrd.github.io/sitemap.xml.
3. Inspect the homepage, publication list, /switchmem/, /CLAG/, /buzzy/, and the
   five /research/ URLs, then request indexing once for each changed page.
4. Use Performance to compare impressions, clicks, queries, and indexed pages
   over the next few weeks. A submission is a crawl hint, not a ranking promise.
