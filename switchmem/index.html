SwitchMem · GUI Agent Memory

Learning How to Remember:
Memory Modality Selection for GUI Agents

Taeyun Roh1, Suhyeong Park1, Gijin Kim1, Wonjune Jang2, Jaewoo Kang1,3

1Korea University · 2Myongji University · 3AIGEN Sciences

nrbsld@korea.ac.kr · kangj@korea.ac.kr

The same experience can help an agent differently when presented as text or an image. SwitchMem learns to select the memory modality that fits each interaction step, giving a frozen GUI agent the right representation of its past experience.

Problem

One memory modality cannot fit every step.

GUI agents reuse demonstrations to navigate unfamiliar interfaces and avoid repeated errors. Most memory systems commit to a fixed representation: text, screenshots, or both together.

Text offers a compact semantic abstraction, while images preserve layout and appearance. Their usefulness changes with the current interface and the action the agent needs to take. SwitchMem treats this choice as part of the interaction loop.

Motivating Observation

Neither text nor images consistently dominate.

With the retrieved demonstration held fixed, Text and Image each win on substantial subsets of interaction steps. A step-wise oracle reveals the headroom left by a fixed memory policy.

Method

From hidden-state shifts to a memory router.

SwitchMem uses the actor's internal response to memory modality as supervision. A lightweight pairwise router then predicts this preference from the current GUI state and the retrieved memory candidates.

01 · Observe

Directional CoE

Run the frozen actor with Text and Image versions of the same retrieved demonstration. Keep the signed hidden-state shift hI − hT at the final prompt token. Deeper layers expose a stronger modality-preference signal.

02 · Learn

Preference supervision

Standardize the final-layer shift, reduce it to 64 dimensions with PCA, and fit a logistic probe on sampled action preferences. Its continuous decision value becomes the target for training a shared MLP scorer.

03 · Select

Step-wise routing

Score both memory candidates against the current-state representation. Select Image when the score difference reaches the calibrated threshold; otherwise select Text. Pass the chosen memory to the frozen actor to generate its next action.

Routing Rule

r = qI − qTr ≥ τ: Image memory   /   otherwise: Text memory

The main experiments use a frozen Qwen3.5-9B actor and Qwen3-VL-Embedding-2B for retrieval and memory embeddings. Both candidates represent the same top-1 retrieved demonstration.

Routing Behavior

The choice changes within a trajectory.

SwitchMem frequently uses both modalities over the course of a task, while retaining a chosen modality for consecutive steps. Its policy adapts to interface state rather than assigning one modality to the entire task.

Analysis

Useful routing depends on which step gets which memory.

Actor-derived preference supervision outperforms simpler routing targets. SwitchMem also beats ratio-matched random selection at every evaluated intermediate Image-use rate on LearnGUI: gains come from assigning modalities to appropriate steps.

UI Density

Visually dense screens

Image memory becomes more useful when fine-grained layouts contain dense UI elements. SwitchMem increases Image selection in these states.

Action Context

Function-oriented actions

The Image-over-Text utility gap grows for actions governing interface functionality, task status, or system navigation.

Trajectory Progress

Evolving interfaces

Image memory becomes more useful after the initial state, as interface changes introduce visual details that textual abstraction may lose.

At inference, SwitchMem obtains a current-state hidden representation for routing and then generates an action with the selected memory. It avoids evaluating both memory-conditioned action prompts online. The latency comparison uses the same RTX PRO 6000 GPU for all methods.

Generalization

The routing formulation works with a GUI-specialized actor.

Applying the preference-construction and routing protocol to UI-TARS-7B-SFT also produces the best scores across all three benchmarks, exceeding its strongest fixed memory condition.

Takeaway

How an agent remembers is part of how it acts.

Retrieving a relevant experience is only part of the problem. Choosing its representation matters too. Memory modality preference varies across steps and is reflected in the actor's internal representations.

SwitchMem turns that signal into a practical routing policy, combining the complementary strengths of text and image memory while providing a single memory modality for each action.
